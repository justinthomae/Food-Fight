# Claude instructions

## Game-dev skills

Before any feature, fix or polish work on this game, use the `grudge-games` skill
(`.claude/skills/grudge-games/`). It picks the right game-dev skills (game feel, UI/UX,
input, audio, performance and more) and runs the polish pass before work is called done.
The rules in this file and any frozen-file lists override the skills' general advice.
